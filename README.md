# Heart-Disease Risk Prediction: Rigorous Re-implementation of Shi, Bechler & Ho

Re-implementation and extension of *"Predicting myocardial infarction risk using supervised and unsupervised
machine learning methods"* using the Kaggle **Heart Attack Analysis & Prediction Dataset** (303 patients, 13 features).

> The target in this dataset is angiographic coronary artery disease (UCI Cleveland), not a documented MI.
> The pipeline checks the label direction automatically and defines `risk = 1` as *disease present*.

## What is improved over the paper
| Area | Paper | This project |
|---|---|---|
| Evaluation | One 60/20/20 split (test n of about 61) | Nested repeated stratified CV, mean ± std, corrected paired tests, one-SE model choice |
| Data quality | Not checked | Duplicates removed; invalid codes (`caa=4`, `thall=0`) imputed in-pipeline; label-direction check |
| Preprocessing | Nominal variables coded as numbers | One-hot encoding inside leakage-free `Pipeline`s |
| Models | 7 families, one split | All families + majority baseline; metrics from `predict_proba` for consistency |
| Calibration / threshold | None; fixed 0.5 | Calibration curves, Brier, slope, recalibration; **nested** threshold for a sensitivity target |
| Fairness | Not measured | Per-sex metrics with bootstrap CIs and male-female gap tests |
| Interpretability | None | Odds ratios with bootstrap CIs; held-out permutation importance |
| Clustering | Unscaled data; settings tuned on labels | Scaled data; silhouette-based selection; paper's setup replicated side by side |

## Setup
```bash
git clone <your-private-repo-url> && cd heart-risk-prediction
python -m venv .venv && source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
Download `heart.csv` from Kaggle and place it in `data/` (see `data/README.md`).

## Run
```bash
python main.py --fast        # ~3 min smoke test
python main.py               # full run (about 15-30 min); writes everything to outputs/
python -m pytest -q          # unit tests
```
Useful options: `--data PATH`, `--out DIR`, `--target-sensitivity 0.95`, `--cal-method sigmoid|isotonic`,
`--flip-label auto|true|false`, `--seed 42`.

Or open `notebooks/heart_risk_analysis.ipynb` and Run All (set `FAST_MODE = True` for a quick test).

### Score new patients
```bash
python predict.py --input new_patients.csv [--output scored.csv]
```
The CSV needs the 13 feature columns. Output: probability of heart disease and a flag at the screening threshold.

### On Kaggle
Upload this repo folder as a Kaggle *Dataset* (e.g. `heart-risk-repo`), add it and the heart dataset as Inputs, then in a
notebook cell run `!python /kaggle/input/heart-risk-repo/main.py` (add `--fast` to test). Results land in `/kaggle/working/outputs`.
To use the notebook instead, change the first lines of its setup cell to
`sys.path.insert(0, "/kaggle/input/heart-risk-repo")`.

## Outputs
| File | Content |
|---|---|
| `tables/cv_summary.csv` | Mean ± std of AUROC, accuracy, precision, recall, F1, Brier for every model |
| `tables/model_comparison_tests.csv` | Corrected paired t-tests vs the best model (Holm-adjusted) |
| `tables/probability_quality.csv` | AUROC, Brier, calibration slope: raw vs recalibrated |
| `tables/operating_points.csv` | Sensitivity/specificity at 0.5, naive threshold, nested threshold (bootstrap CIs) |
| `tables/performance_by_sex.csv`, `sex_gaps.csv` | Per-sex metrics and male-female gaps |
| `tables/odds_ratios.csv`, `permutation_importance.csv` | Interpretability |
| `tables/kmeans_*.csv`, `dbscan_grid.csv` | Unsupervised results |
| `figures/fig_*.png` | EDA, split instability, CV boxplots, calibration/threshold, importance, clustering |
| `final_summary.txt` | Paper-vs-this-work summary with all numbers generated by code |

## Reproducibility
Fixed seed (`--seed`), pinned search spaces in `src/models.py`, all preprocessing inside pipelines, all numbers produced by code.

## Git workflow (for the individual-contribution grade)
Work on feature branches (`feature/calibration`, `feature/fairness`, ...), commit often with clear messages, merge via pull requests,
and keep each member's work visible in `git log`. Share the private repo with the faculty and TAs.

## Limitations
Single-centre, about 300 patients, no external validation; outcome is angiographic disease rather than documented MI;
subgroup (female, n of about 96) estimates have wide CIs. Not a medical device.
